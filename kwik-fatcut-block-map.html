Global Rules

Rules that apply to every page.

These settings are non-negotiable across the entire site. Set them globally in Kadence settings and do not override per-page unless specifically noted.

Exact Brand Colours

Background#1A0E08 — dark earth
Gold#DAA520 — gold leaf
Green#2E6B3E — rainforest
Red#C1440E — terracotta
Cream#FDF5E6 — old lace

Typography

Display / Headings

Cormorant Garamond — Heading Italic

Google Fonts — weights: 300 (primary), 400, 600 | Always load italic variants

Body / UI

DM Sans — body text and all UI elements

Google Fonts — weights: 300, 400, 500 | Default weight: 300

Navigation (Every Page)

  • Fixed, transparent-to-opaque gradient
  • Logo left: Cormorant Garamond, gold italic on "Fat Cut"
  • Links: DM Sans 0.74rem, uppercase, letter-spacing 0.13em
  • Active link: colour #DAA520
  • CTA button: bg #DAA520, text #1A0E08, no radius
  • Mobile: hide all links except CTA button

Footer (Every Page)

  • 3-column flex: logo+tagline | nav links | copyright
  • Border top: rgba(253,245,230,0.07)
  • Tagline: "A knowledge tree for health, wellness, awareness & opportunity."
  • Nav links: 5 pages max, small caps, muted colour
  • Mobile: stack vertically, align left

Social Strip (Every Page)

  • Position: above footer, below CTA strip
  • Exception: support.html — after donation panel
  • Share button uses Web Share API with clipboard fallback
  • Follow link → kwikfatcut.com (update when live URLs confirmed)
  • Social links → update with real platform URLs before launch

Scroll Reveal Animations

  • All .reveal elements: opacity 0 → 1, translateY 24px → 0
  • Trigger: IntersectionObserver, threshold 0.07
  • Stagger: 65ms delay between sibling elements
  • If Kadence scroll reveal is insufficient, use the JS from HTML reference
  • Hero elements: CSS animation, not IntersectionObserver

Dividers / Rules

  • Horizontal rules between sections: 1px height
  • Colour: linear gradient — transparent → rgba(218,165,32,0.15) → transparent
  • Margin: 0 6vw (inset from page edges)
  • Use Kadence divider block with custom colour

Grain Texture Overlay

  • Fixed position, covers entire viewport, z-index 998
  • SVG fractalNoise filter, opacity 0.45
  • Pointer-events: none (non-interactive)
  • Implement via Kadence Custom CSS or child theme — applies to body::after globally

What NOT to Do

  • Do not change any hex colour
  • Do not substitute fonts
  • Do not add sections, cards, or blocks not in the reference
  • Do not reorder sections
  • Do not add hover effects beyond what the HTML shows
  • Do not suggest design improvements — ask first

Logo Usage

  • File: kwik-logo.jpeg — upload to Media Library
  • Hero (Our Roots): clamp(180px,26vw,300px) wide, drop-shadow gold glow
  • Founder page right panel: 65% width, opacity 0.6
  • Article sidebars: 120px wide
  • Nav: text-based logo only — no image in nav
